## Run the tests

- **IntelliJ IDEA:** open `src/test/java/ReceiptTest.java` and click the green ▶
  next to `class ReceiptTest`.
- **Terminal (macOS/Linux):** `./mvnw test`
- **Terminal (Windows):** `mvnw.cmd test` (in PowerShell: `.\mvnw.cmd test`)

The first run downloads what it needs, so give it a minute. Push your work and
GitHub runs the same tests. A green tick means you passed.
